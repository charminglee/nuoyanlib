# 「nuoyanlib」开发指南

## 安装 Python

- [Python 3.12](https://www.python.org/downloads/release/python-31210/) （日常开发）
- [Python 2.7](https://www.python.org/downloads/release/python-2718/) （测试）

验证安装：

```powershell
py -0p
```

## 安装虚拟环境

### Python 3 环境

建议使用 Python 3 进行日常开发，开发脚本也需使用 Python 3 运行。

在项目根目录运行以下指令以创建 Python 3 虚拟环境：

```powershell
py -3.12 -m venv .venv3
.venv3\Scripts\python.exe -m pip install -r requirements.txt
```

> [!NOTE]  
> 该环境已预装 [ModSDK 补全库修正版](https://github.com/charminglee/mc-netease-sdk-nyrev) 。

### Python 2 环境

为保证测试可靠性，运行测试脚本时需要使用与游戏一致的 Python 2.7 版本。

在项目根目录运行以下指令以创建 Python 2 虚拟环境：

```powershell
py -2.7 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements2.txt
```

## 项目结构

项目根目录按源码、游戏资源、开发脚本、测试和文档划分：

```
nuoyanlib/
├── assets/                  # 行为包和资源包资源
│   ├── behavior_pack/
│   └── resource_pack/
├── demo/                    # 示例项目
├── docs/
│   ├── dev/                 # 开发文档
│   └── source/              # API 文档源文件
├── scripts/                 # 开发脚本
├── src/
│   └── nuoyanlib/           # 「nuoyanlib」源码
├── tests/
│   ├── ide_test/            # 可在本地 Python 2 环境验证的测试包
│   └── ingame_test/         # 需要在游戏内验证的测试包
├── ...
```

「nuoyanlib」各目录职责如下：

```
src/nuoyanlib/
├── client/          # 存放客户端接口
├── server/          # 存放服务端接口
├── common/          # 存放通用接口
├── core/            # 库内部实现，不作为业务代码的直接依赖
│   ├── _types/      # 用于类型检查的模块
│   ├── client/      # 库内部系统的客户端实现
│   └── server/      # 库内部系统的服务端实现
├── extensions/      # 可选扩展模块
├── config.py        # 全局配置
├── ...
```

## 测试

修改接口后请编写对应的测试用例并进行验证。

对于无需游戏实机环境验证的测试，可在 `/tests/ide_test/case` 中编写，测试模块的命名规范为 `test-<减号分隔的原模块路径>.py` 。
例如要测试 `nuoyanlib.common.mc_math.vector` 模块，则测试模块应命名为 `test-common-mc_math-vector.py` （省略 `nuoyanlib` ）。

使用以下指令运行测试：

```powershell
.venv\Scripts\python.exe tests\ide_test\main.py
```

对于需要游戏实机环境验证的测试，请写在 `/tests/ingame_test/bp/test_scripts` ，并启动 ModPC 加载运行。
