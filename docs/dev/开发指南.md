# 「nuoyanlib」开发指南

## 安装 Python

- [Python 3.12](https://www.python.org/downloads/release/python-31210/) （日常开发）
- [Python 2.7](https://www.python.org/downloads/release/python-2718/) （测试）

验证安装：

```powershell
py -0p
```

## 安装虚拟环境

### Python 3 环境

建议使用 Python 3 进行日常开发，开发脚本也需使用 Python 3 运行。

在项目根目录运行以下指令以创建 Python 3 虚拟环境：

```powershell
py -3.12 -m venv .venv3
.venv3\Scripts\python.exe -m pip install -r requirements3.txt
```

> [!NOTE]  
> 该环境已预装 [ModSDK 补全库修正版](https://github.com/charminglee/mc-netease-sdk-nyrev) 。

### Python 2 环境

为保证测试可靠性，运行测试脚本时需要使用与游戏一致的 Python 2.7 版本。

在项目根目录运行以下指令以创建 Python 2 虚拟环境：

```powershell
py -2.7 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 项目结构

项目根目录按源码、游戏资源、开发脚本、测试和文档划分：

```text
nuoyanlib/
├── assets/                  # 行为包和资源包资源
│   ├── behavior_pack/
│   └── resource_pack/
├── demo/                    # 示例项目
├── docs/                    # 项目文档
│   ├── dev/                 # 开发指南和编码规范
│   └── source/              # API 文档源文件
├── scripts/                 # 开发辅助脚本
├── src/
│   └── nuoyanlib/           # 库源码
├── tests/
│   ├── ide_test/            # 可在本地 Python 环境运行的测试
│   └── ingame_test/         # 需要在游戏内运行的测试包
├── requirements.txt         # Python 2.7 测试环境依赖
├── requirements3.txt        # Python 3 开发环境依赖
└── README.md
```

库源码位于 `src/nuoyanlib/`，各目录职责如下：

```text
src/nuoyanlib/
├── __init__.py              # 包入口
├── config.py                # 库配置
├── client/                  # 仅客户端可用的公共接口
│   └── ui/                  # 客户端 UI 工具
├── server/                  # 仅服务端可用的公共接口
├── common/                  # 客户端和服务端均可用的公共接口
│   └── mc_math/             # 与 Minecraft 相关的数学工具
├── core/                    # 库内部实现，不作为业务代码的直接依赖
│   ├── _types/              # 内部类型定义
│   ├── client/              # 客户端内部实现
│   └── server/              # 服务端内部实现
└── extensions/              # 可选扩展模块
    └── item_grid/           # 物品栏网格扩展
```

公共模块的实现文件使用 `.py`，对应的 `.pyi` 文件用于 IDE 类型提示。编写业务代码时，应从 `client`、`server` 或 `common` 导入接口，不要直接依赖 `core` 内部模块。`client` 只能在客户端运行，`server` 只能在服务端运行，`common` 才能在双端共享。
